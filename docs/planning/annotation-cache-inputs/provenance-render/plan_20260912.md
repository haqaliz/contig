## Edge cases

- Legacy records without the four keys: byte-identical renders (pinned).
- `--opt`-supplied values appear in `record.parameters` the same way — renderer
  is key-based, so it cannot distinguish flag from `--opt`; that is correct
  (both are user-supplied inputs).
- A record with `download_cache` present but `"false"`: no "cache download"
  wording (only `"true"` renders it) — user-supplied caches are the
  `vep_cache`/`snpeff_cache` keys.
