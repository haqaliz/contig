## Task 1 — Seam logic: user caches + explicit-mode guard (TDD, pure params level)

**Goal:** `_enable_annotation_cache` (cli.py:486-513) takes `vep_cache` and
`snpeff_cache` keyword args and implements the M2/M3 logic.

**Files:** `src/contig/cli.py` (only `_enable_annotation_cache`); new
`tests/test_annotation_cache_inputs.py`.

**Steps:**
1. RED: write direct-call unit tests (parent test 5 style, `test 1-7` below)
   against the extended function. Call shape: `_enable_annotation_cache(params,
   assay=..., pipeline=..., revision=..., runs_dir=..., engine="nextflow",
   vep_cache=..., snpeff_cache=...)` — for existing-call back-compat the new
   args default `None`.
2. GREEN: implement inside the function, before the current `mkdir` block:
   - `if vep_cache: params.setdefault("vep_cache", vep_cache)` and same for
     `snpeff_cache` (setdefault ⇒ `--opt` values already in `params` win).
   - `has_vep = params.get("vep_cache") is not None`,
     `has_snpeff = params.get("snpeff_cache") is not None`.
   - `explicit = "genome" not in params and ("fasta" in params or "gtf" in
     params)` (post-`resolve_reference`, `reference.py:27,41`).
   - If `explicit and not (has_vep and has_snpeff)`: stderr message naming
     `--vep-cache` and `--snpeff-cache` (state that explicit-reference variant
     runs need both, and that `--opt vep_cache=…` also works), then
     `raise typer.Exit(code=1)` — before any `mkdir`.
   - The existing auto-download block (`mkdir` + two setdefaults) runs only when
     `not (has_vep and has_snpeff)` (i.e. at least one tool lacks a user cache:
     test-profile/iGenomes status quo; iGenomes single-cache leaves the missing
     tool on auto-download, PRD R3).
   - Keep the existing early return gate (`engine != "nextflow"` or assay not in
     `VARIANT_ASSAYS`) unchanged.
3. REFACTOR: keep the function small; docstring updated to name the new
   contract (user caches win; explicit refusal; all-or-nothing in explicit
   mode).

**Validation:** `uv run pytest tests/test_annotation_cache_inputs.py -q` green;
`uv run pytest tests/test_annotation_cache_wiring.py -q` green unmodified.

**Tests to write (params-level):**
1. both caches via kwargs → `params` carry both, no `download_cache`/
   `outdir_cache` keys, no `caches/` dir created.
2. both caches via kwargs + pre-set `params["vep_cache"]` → pre-set wins
   (setdefault).
3. explicit mode (params pre-seeded with `fasta`/`gtf`) + no caches → `Exit(1)`,
   message names both flags, no `mkdir`, no params mutation.
4. explicit mode + exactly one cache → `Exit(1)`, message names both flags.
5. explicit mode + both caches → no refusal, no download keys, launch params
   intact.
6. iGenomes mode (params pre-seeded with `genome`) + no caches → download keys
   injected + dir created (status quo).
7. iGenomes mode + both caches → no download keys.
8. iGenomes mode + only `vep_cache` → `vep_cache` kept AND `download_cache`/
   `outdir_cache` injected (R3).
9. non-variant assay (e.g. rnaseq) + caches kwargs → early return, params
   untouched.

**Commit:** `feat(annotation): user cache params + explicit-reference guard in the cache wiring seam (C7 follow-on)`
