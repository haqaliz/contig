## Edge cases & error handling

- Missing/unreadable known-sites file → `sha256 None`, pre-flight warning, run proceeds.
- iGenomes genome key not in the asset map → known-sites absent (never guessed).
- `genome` + explicit `dbsnp` mixed → iGenomes mode records both the key and the
  explicit dbsnp (honest: the explicit value overrides for that role).
- `.tbi` sidecars: never hashed, never stored.
- Legacy manifests/bundles (no keys) → load with `None`.
- Non-variant assay with known-sites flags → refused at pre-flight.
- Signature: old signed bundles → `signature_ok: False`, never silently re-signed.
