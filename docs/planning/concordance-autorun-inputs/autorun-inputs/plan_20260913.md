## Locked design decisions (from PRD review)

1. **Reads fallback lives in a small helper** `_derive_reads(record, explicit_reads,
   run_id) -> tuple[str | None, str | None]` in `cli.py` — returns the derived
   reads path + an honest skip note (or `None` when nothing to derive). Pure of
   CLI side effects (file hashing is I/O but no echo/exit). Explicit `--reads`
   bypasses the helper entirely — the integrity gate guards **derived** reads only
   (PRD's hard-question line, user-approved).
2. **Integrity gate:** when deriving, hash the sheet + its FASTQs (reuse
   `compute_input_checksums` from `bundle.py:132-144` if its shape fits —
   otherwise mirror it; read it first) and compare against `record.input_checksums`
   (basename → sha256). Skip on: no `parameters["input"]`; sheet missing on disk;
   **empty** `input_checksums` (test-profile/legacy — cannot verify);
   any basename mismatch in either direction.
3. **`--transcriptome` replaces `--index`** for `--concordance-counts-auto` only.
   `--index` + `--transcriptome` → refusal, exit 1. Without the auto flag it is
   ignored like `--reads`/`--index` (docstring note; the existing precedent —
   `cli.py:1752-1753`).
4. **t2g writer contract:** `_parse_t2g` (`count_quantifier.py:124-136`) reads
   `fields[0]` = transcript_id, `fields[1]` = gene_id, extra columns ignored — so
   the writer emits `transcript_id\tgene_id` and a third `gene_name` column when
   the GTF carries it (kb-ref-compatible; the reader tolerates it).
5. **Build seam:** `build_kallisto_index(transcriptome, index_dir, builder=None)`
   in `count_quantifier.py`, argv `kallisto index -i <index_dir>/index.idx
   <transcriptome>`; default builder shells out via `subprocess.run` and raises
   `SecondQuantifierError` on missing binary/nonzero exit; tests inject a fake.
   The built dir must contain `index.idx` + written `t2g.txt` so the **unchanged**
   `run_kallisto_quantifier` accepts it (`index_path.is_dir()` + `tx2gene_path`
   exist checks, `:160-161,197-202`).

## Edge cases & error handling

- Sheet/FASTQ missing on disk → skip, never a spawn (checksums can't be computed
  against nothing).
- Empty `input_checksums` → skip (cannot verify; test-profile/legacy records).
- Checksum mismatch either direction (recorded basename absent on disk, or a
  disk basename not in the record) → skip, fail closed.
- Duplicate FASTQ basenames across dirs → inherited basename-keyed collision;
  can only fail closed (mismatch → skip), never silently compare changed input.
- GTF with no transcript lines / unreadable / GFF3-shaped attributes → honest
  skip BEFORE any build spawn.
- `--index`+`--transcriptome` → refusal; `--transcriptome` without the auto flag
  → ignored (docstring note, reads/index precedent).
- Build nonzero exit or missing binary → named error → skip note; quantifier
  never invoked.
- iGenomes record (no local `parameters["gtf"]`) + `--transcriptome` → skip
  ("pass `--index`").
- Explicit `--reads`/`--index` → byte-identical behavior, no gate.
