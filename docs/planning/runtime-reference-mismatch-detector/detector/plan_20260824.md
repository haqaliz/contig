     ```python
     # Reads whose contigs are absent from the reference FASTA -- a hard-fail
     # signature of the wrong-genome class (reference/build mismatch at
     # runtime). Narrow on purpose: a matched line must carry a
     # contig-absence phrase AND a contig/sequence token, so the branch never
     # steals from the missing_index family (index-token anchored) or
     # missing_reference ("no such file or directory" anchored). GATK's
     # "incompatible contigs" wording is deliberately NOT here (decision:
     # control negative, stays tool_crash).
     mismatch_lines = _matching_lines(log_text, ("not found in the reference",))
     if mismatch_lines and _has_any(log_text, ("contig", "sequence", "'chr")):
         return Diagnosis(
             failure_class="reference_mismatch",
             root_cause=(
                 "Reads or annotations reference contigs absent from the "
                 "reference FASTA - the wrong genome build was likely used."
             ),
             evidence=mismatch_lines,
             confidence=0.85,
         )
     ```
     (Exact phrase/guard tuple is pinned by the tests above; if a test needs a
     different spelling, the test wins -- change the tuple, keep the family
     tight.)
   - Placement note: do NOT touch the stall/OOM priority head or any
     `missing_index` branch; the new branch only claims logs that survive them.

3. **Validation:** `uv run pytest tests/test_detect.py -x` green;

## Edge cases & error handling

- Twin fails to classify → **disclose as known-miss** (never force the needle);
  baseline stays 13/14; CHANGELOG records it.
- heal-guard outcome-match drops below 1.0 → the scenario is wrong; fix the
  scenario, never the baseline.
- Phrase/guard tuple collides with `missing_index`/`missing_reference` logs →
  the control tests pin the boundaries; if a real collision appears, narrow the
  guard (the tests are the contract).
- Wrong-reference run that completes green + QC FAIL → `qc_anomaly` (Phase 4
  pin); the detector branch only sees failed-task events.
- Existing `--allow-reference-mismatch` flag / `LaunchManifest`
  `allow_reference_mismatch` field share the Python name but are a different
  layer -- do not rename or touch them.
