- **Steps:**

     ```python
     class VerificationCase(BaseModel):
         case_id: str
         description: str
         source: str  # "synthetic" | "pending:<run_id>" | "confirmed:<run_id>"
         assay: str
         inputs: dict[str, dict[str, dict[str, float]]]  # family -> sample -> metric -> value
         expected_verdict: QCStatus | None = None  # None until promoted
     class FamilyScore(BaseModel):
         matched: int; total: int; rate: float
     class VerifyCaseResult(BaseModel):
         case_id: str; predicted_verdict: QCStatus; expected_verdict: QCStatus | None
         matched: bool; families: dict[str, str]  # family -> reduced status
         divergence: list[str]  # families whose status changed vs expected, or reasons
     class VerifyEvalReport(BaseModel):
         total: int; correct: int; verdict_match_rate: float
         per_family: dict[str, FamilyScore] = {}
         mismatches: list[VerifyCaseResult] = []
     class VerifySnapshot(BaseModel):
         timestamp: str; case_count: int; corpus_sha: str
         verdict_match_rate: float; per_family: dict[str, FamilyScore] = {}
         contig_version: str | None = None
     class VerifyGuardResult(BaseModel):
         case_count: int; verdict_match_rate: float
         baseline_rate: float | None = None; delta: float | None = None
         tolerance: float; regressed: bool = False; improved: bool = False
         corpus_sha: str; baseline_sha: str | None = None
         sha_mismatch: bool = False; has_baseline: bool = True
         mismatches: list[VerifyCaseResult] = []
     ```
  3. REFACTOR: none needed; keep fields minimal (no informational field beyond
     what reduction needs).

## Phase 2: The scorer (TDD)

- **Goal:** `src/contig/verify_corpus.py` — I/O + family→pack table +
  `evaluate_verify_case` + `evaluate_verify` (pure, no I/O).
- **Files:** `src/contig/verify_corpus.py` (new), `tests/test_verify_corpus.py` (new).
- **Steps:**
  1. RED first for each behavior below (write the test, watch it fail):
     - **Family→pack table.** `_FAMILY_PACKS: dict[str, list[dict]]` mapping:
       `multiqc` → resolved per assay via `rule_pack_for(case.assay)`;
       `rnaseq_plausibility` → `RNASEQ_PLAUSIBILITY_PACK`;
       `rnaseq_composition` → `RNASEQ_COMPOSITION_PACK`;
       `somatic_plausibility` → `SOMATIC_PLAUSIBILITY_PACK`;
       `annotation_plausibility` → `ANNOTATION_PLAUSIBILITY_PACK`;
       `scrnaseq` → `SCRNASEQ_RULE_PACK`; `methylseq`/`ampliseq`/`mag` → their
       packs; `germline` → `VARIANT_RULE_PACK`.
       For `multiqc`, resolve at evaluation time from the case's assay and
       `rule_pack_for` (raise ValueError for unknown assay → case degrades to
       `unverified` predicted, never crashes the guard).
     - **Concordance families.** `_CONCORDANCE_STATUS(inputs: dict[str, float])`
       — a pure function taking stored signal values:
       `{"value": v, "n_shared": n, "kind": "spearman|genotype|somatic_overlap|consequence"}`;
       re-derives status under the CURRENT thresholds (imported constants):
       `n < MIN` → `unverified`; `v < WARN_BELOW` → `warn`; else `pass`.
       Per-kind thresholds from the modules listed in Design pins.
     - **`evaluate_verify_case(case)` → `VerifyCaseResult`:**
       - For each family in `case.inputs`: run `evaluate(metrics, pack)` (or the
         concordance re-deriver) → results; family reduced status =
         `overall_verdict(results)` semantics BUT per-family: use
         `_family_status(results)` = the worst non-informational status
         (`fail > warn > pass > unverified`), `unverified` if no non-informational
         results. Store `families[family] = status`.
       - `predicted_verdict` = worst status across families (same order).
       - `matched = (expected_verdict is not None) and (predicted == expected)`.
       - `expected_verdict=None` → `matched=False` but excluded from the report
         tally (see next step).
       - `divergence` lists the families whose reduced status is `unverified`
         (honest: not scoreable) or, on a mismatch, the expected vs predicted.
     - **`evaluate_verify(cases)` → `VerifyEvalReport`:** totals over cases with
       `expected_verdict is not None` only; `verdict_match_rate = correct/total`;
       per-family `FamilyScore` over the same labeled subset; `mismatches` =
       labeled cases with `matched=False`.
  2. Tests must include: a passing case (predicted == expected), a failing
     case, a WARN case, an unlabeled case excluded from the rate, an unknown-assay
     case degrading to `unverified` predicted (and therefore a mismatch when
     labeled), a concordance family case at each boundary
     (n_shared=9 → unverified; v=0.89 → warn; v=0.91 → pass).
  3. **The mutation control test (the anti-tautology pin):** build a case whose
     stored `ts_tv = 0.5` in family `germline`; assert predicted `fail`
     (fail_below 1.2). Then monkeypatch the pack (or use a tmp pack injected via
     a seam) so the band is `fail_below 0.3`; assert the same case now predicts
     `pass`. The scorer must accept an injected pack mapping (constructor/arg
     seam `_FAMILY_PACKS` overridable) so the test mutates bands without editing
     committed data. This test is the RED that proves band-sensitivity before the
     seed exists.
- **Validation:** `uv run pytest tests/test_verify_corpus.py`; full suite green.
- **Commit:** `feat(verify): band-sensitive verification-case scorer (C6 fold-in)`

## Edge cases & error handling

- Unknown assay / unknown family → that family's status `unverified`, never a
  crash; labeled case counts as a mismatch (honest), unlabeled excluded.
- Family with no results (missing metrics) → `unverified`.
- Blank lines / malformed JSONL → skipped on load (snapshot_history.py
  precedent, heal.py:320-327).
- Empty inputs dict → predicted `unverified`.
- Float noise: `compare_verify_to_baseline` tolerance param (default 1e-9).
