## Design pins

- The source of truth is `models.py`'s `FailureClass` (18 literals). The TS
  list is documented as a mirror — keep the same order as the Python literal
  to make future drift greppable.
- The five missing literals: `reference_not_bgzf`, `missing_dependency`,
  `disk_full`, `download_failed`, `permission_denied`.
