## Environment & reproducibility

- The baseline/history are committed data; `corpus_sha` ties them to the seed
  bytes. Refreeze only via `--update-baseline` (deliberate, reviewed).

## Edge cases & error handling

- Missing corpus file → exit 1 naming the path (heal_guard precedent).
- Missing baseline → exit 1 with `--update-baseline` hint.
- sha mismatch → loud warning, non-failing by itself.
- All-unlabeled corpus (empty goldens path) → rate 0.0 with no labeled cases;
  the guard still runs (report total 0) — the committed holdout never hits
  this; a tmp `--corpus` with only unlabeled cases is a legal degenerate input
  and must not crash (pin in tests if cheap).
