### Task 2: Corpus core module (`src/contig/reproduce_corpus.py`)

- **Goal:** gate, builder, sidecar I/O, promote, scorer, snapshot — all pure.
- **Prerequisites:** Task 1.
- **Files:** new `src/contig/reproduce_corpus.py`; new `tests/test_reproduce_corpus.py`.
- **Steps (TDD):** implement in this order, one RED→GREEN cycle each:
  1. Paths: `default_reproduce_corpus_path()` → `data/reproduce_corpus.jsonl`
     (deliberately NOT the guard's scenario file — mirror
     `default_verify_golden_path`, verify_corpus.py:305-311); history →
     `data/reproduce_corpus_history.jsonl`.
  2. `should_capture_reproduce(record) -> bool` — the spec gate (AC1). Test a clean
     record (all reproduced/within_tolerance, exit 0, no repair) → False; each
     interesting variant → True.
  3. `reproduce_case_from_record(record, *, claims=None)` — build per spec; family
     via `claim_family(claim)` matched on `claim.id`; unmatched → `"unknown"`;
     `claims=None` → all families `"unknown"` (never fabricated, never crash);
     `repair` from `repair_history[-1].outcome` else `None`; description names the
     run's interesting signal (claims + repair + exit).
  4. `append_reproduce_case` / `load_reproduce_cases` / `save_reproduce_cases` —
     mirror verify_corpus.py:314-345 (blank/malformed lines skipped; parent dir
     created on append). AC2.
  5. `promote_reproduce_case(case_id, pending, golden, *, expected_claims=None,
     expected_repair=None, expected_exit_code=None)` — mirror
     `promote_pending_verify_case` (verify_corpus.py:492-531): missing id raises
     `ValueError`, duplicate raises `ValueError`, `pending:`→`confirmed:`, apply
     labels (validate claim ids against the case, unknown → `ValueError`), append to
     golden + save pending minus the case. AC3.
  6. `evaluate_reproduce_case(case, *, classifier=None)` +
     `evaluate_reproduce_cases(cases, *, classifier=None)` — classifier defaults to
     `classify` (the shipped `(claimed, observed, tolerance) -> (status, delta,
     msg)`); claim match only when `expected_status` set and equal; case match adds
     `expected_repair`/`expected_exit_code` when set; report totals over labeled
     claims only; `per_family` via `FamilyScore`; mismatches informational.
     **Mutation pin test (AC5):** a stored `diverged` case with a mutated classifier
     (looser tolerance) re-derives `within_tolerance`/`reproduced` — proving inputs
     are stored, not statuses; an unlabeled claim never contributes a match.
  7. `snapshot_from_reproduce_report(report, *, corpus_sha, timestamp, contig_version)` —
     mirror `snapshot_from_verify_report` (verify_corpus.py:366-385).
- **Validation:** `uv run pytest tests/test_reproduce_corpus.py -q` green; full suite
  green.

## Edge Cases & Error Handling

- Malformed/blank pending lines: skipped on load, never raise.
- `claims=None` or unmatched claim id in the builder: family `"unknown"`, never
  fabricated, never crash.
- Partial labels: unlabeled claims excluded from `claim_match_rate`, never a
  mismatch.
- Promote crash between append-golden and rewrite-pending: leaves the case in both
  files; a re-run hits the dedupe error — accepted, mirrors the verify precedent.
- Bundle-write failure: no capture (capture runs after the write succeeds).
- Unknown locator families in `per_family`: counted under their own key, never crash.
