### Task 1 — Data shapes + safe walk (R1, R2)

> **Ruling (pre-flight):** R3 (the 8 MiB size bound) was listed here but is tested in Task 4
> (A2). The bound belongs with the per-artifact `stat()` in `sweep_repo`, not in the walk.
> R3 is Task 4's. Do not implement a size check here.

**Files:** create `src/contig/verification/locator_inference.py`;
create `tests/verification/test_locator_sweep.py`.

**Tests first (RED):**
- `.git` pruned at top level **and** nested (`a/.git/b.json` not yielded).
- Symlinked file skipped; symlinked directory not descended.
- Only `.json`/`.tsv`/`.csv`/`.tsv.gz`/`.csv.gz` yielded; `.txt`/`.ipynb`/`.log` not.
- Output sorted by POSIX relative path (assert exact list).
- Missing / non-directory repo root → empty, no raise.

**Implement (GREEN):**
```python
@dataclass(frozen=True)
class Candidate:
    source: str                     # repo-relative POSIX path == the locator "from"
    kind: str                       # "json" | "table"
    value: float
    path: str | None = None         # kind == "json"
    column: str | int | None = None # kind == "table"
    row: int | None = None          # kind == "table"
    header: bool | None = None      # kind == "table"

@dataclass(frozen=True)
class SweepSkip:
    source: str
    reason: str

def iter_artifacts(repo: Path) -> list[Path]: ...
```
`os.walk(followlinks=False)`; mutate `dirnames` in place to prune `.git` and symlinked dirs;
`Path.is_symlink()` to skip symlinked files.

**Verify:** `rtk proxy uv run pytest tests/verification/test_locator_sweep.py -q`
**Commit:** `feat(reproduce): safe artifact walk for locator inference (candidate-sweep 1/4)`

### Task 2 — JSON candidate enumeration (R4, D1, D4, D5)

**Tests first (RED):**
- Flat `{"auc": 0.91}` → one candidate, `path == "auc"`.
- Nested `{"m": {"auc": 0.91}}` → `path == "m.auc"`.
- List `{"xs": [1.5, 2.5]}` → `xs[0]`, `xs[1]`.
- List of dicts `{"rows": [{"v": 3.0}]}` → `rows[0].v`.
- **A3 round-trip pin:** for every candidate, `resolve_pointer(doc, cand.path) == cand.value`.
  Table-drive this over a fixture doc exercising all four shapes.
- **A7:** `true`/`false` (D4), `null`, and the numeric **string** `"0.91"` (D5) are never
  candidates; `nan`/`inf` never candidates.
- **A6:** key `"a.b"` or `"x[0]"` → skipped with a reason, not emitted.
- Malformed JSON → `SweepSkip`, no raise (A9).

**Implement (GREEN):** `_json_candidates(source, text) -> tuple[list[Candidate], list[SweepSkip]]`.
Recursive walk building the path incrementally. Guards, in order: expressibility of the key
(D1) → `bool` rejection (D4) → `int`/`float` only, never `str` (D5) → `math.isfinite`.

**Verify / Commit:** `feat(reproduce): JSON numeric-leaf candidate enumeration (candidate-sweep 2/4)`

### Task 3 — Table candidate enumeration (R5, D2, D3)

**Tests first (RED):**
- Header-ful TSV → string column names; `row` indexes **data rows** (`rows[1:]`), so the first
  data row is `row=0`.
- Headerless (numeric first row) → integer column indices, `header=False`.
- **A4 round-trip pin:** `resolve_cell(rows, c.column, c.row, c.header)` floats to `c.value`.
- `.csv`, `.tsv.gz`, `.csv.gz` all enumerate (reuse `test_reproduce.py:358/:368` fixture style).
- Ragged row → shorter row contributes only its real cells, no raise (A9).
- Non-numeric cells skipped; a numeric **string** cell **is** a candidate (D5).
- Empty table → no candidates, no raise.
- **Duplicate header names** → those columns skipped with a reason (`resolve_cell` would call
  them ambiguous, `reproduce.py:263`, so emitting them proposes an unresolvable locator).

**Implement (GREEN):** `_table_candidates(source, path) -> tuple[list[Candidate], list[SweepSkip]]`
via `_read_table(path, delimiter)` with the extension-derived delimiter used **only** for
reading — never emitted (D3).

**Verify / Commit:** `feat(reproduce): table cell candidate enumeration (candidate-sweep 3/4)`

## 3. Testing strategy

- **Unit:** phases 1–3, pure functions, `tmp_path`.
- **Round-trip (the load-bearing ones):** A3/A4 prove reuse of the shipped resolvers rather
  than a parallel reimplementation. If these pass, the coordinates we emit are exactly the
  coordinates the engine reads. **If an agent is tempted to weaken A3/A4, stop and escalate.**
- **Never-raises:** A10, wild inputs.
- **Commands:** `rtk proxy uv run pytest tests/verification/test_locator_sweep.py -q` per
  phase; `rtk proxy uv run pytest -q` before the final commit. No dashboard work in this aspect.

## 4. Edge cases already decided (do not re-litigate mid-phase)

| Case | Behaviour | Source |
|---|---|---|
| Key with `.` or `[` | skip + reason | D1 |
| First row all non-numeric | header | D2 |
| `delimiter` | never emitted | D3 |
| `bool` / non-finite | never a candidate | D4 |
| JSON numeric string | not a candidate | D5 |
| Table numeric string | **is** a candidate | D5 |
| Duplicate header names | skip those columns | Phase 3 |
| Oversized artifact | skip naming size | R3/A2 |

## 5. Agent execution notes

- **Checkpoint after Phase 2.** The A3 round-trip pin is where a subtly wrong path grammar
  shows up. Have a human (or the integrator) read the generated path expressions before
  Phase 3 builds on the same pattern.
- **Escalate, do not decide:** promoting `_read_table` to public (breaks A11); any change to a
  shipped file; weakening A3/A4; adding a dependency.
- **Likely iteration:** D2 header detection and the `[n]`/`.isdecimal()` path grammar.
- **Do not build ahead.** Matching, rounding, `÷100`, the exactly-one rule and M9's
  low-information refusal are **aspect 2**. A sweep that "helpfully" matches a claim has
  broken the aspect boundary and the evidence gate that depends on it.
- **Layer check:** pure Layer 2 (reproduce/verify). No NL→workflow surface anywhere here.
