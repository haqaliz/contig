## 2. Command surface (pinned by the spec)

```
contig infer-locators <repo> <claims.json> --out <out.json>
                      [--metrics <metrics.json>] [--force] [--dry-run]
```

- `repo`: local directory only — call `classify_repo_argument(repo)` (from
  `contig.fetch`), accept ONLY `kind == "local"` (URL/DOI → its refusal
  message, exit 1); then `Path(repo).is_dir()` → else exit 1 (mirror
  `cli.py:1155-1159`). Leading-`-` refusal comes free from the classifier.
- `claims.json`: `load_claims(path)` (unchanged); `ClaimsError` or
  unreadable/missing → exit 1 naming the reason, nothing written.
- `--out`: required. Guard order mirroring extract-claims:
  1. `--out` resolves equal to the claims input path → exit 1
     (`try/except OSError` → False, per `cli.py:1461-1471`);
  2. `out.exists() and not force` → exit 1;
  3. out parent dir missing → exit 1 (mirror `cli.py:1482-1485`).
- `--metrics <json>`: optional. Load + validate: JSON object; root must be a
  plain dict; each value must be a list of non-empty strings; claim ids are
  strings. Violation → exit 1 naming the reason. Absent → `metrics=None`
  (value-only) + echo "no --metrics given; running value-only (semantic
  filter off)".
- `--force`, `--dry-run`: bool flags.

## 6. Edge cases & error handling

- URL/DOI/`-`-leading repo args → the classifier's refusal messages (exit 1),
  never "not a directory".
- `--metrics` staleness: unknown ids fall back silently in the MATCHER by
  design; the CLI makes it visible (echo count) — the spec's fix.
- Empty claims file (`[]`) → sweep still runs, no outcomes, out written as
  `[]` (mirror extract-claims' empty-draft exit 0), sidecar notes zero
  claims.
- `--dry-run` must not create the temp file — the mkstemp happens only on
  the write path.
- A claim whose bound locator came from a `.gz` table — `load_claims`
  re-derives the delimiter from the extension; the emitted dict omits it
  (already pinned by the matcher's M6 tests; the CLI test re-pins the file
  round-trip).
- Nothing written on ANY refusal (assert out absent on each guard failure).
