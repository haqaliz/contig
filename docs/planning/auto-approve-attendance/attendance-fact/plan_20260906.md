## Phase 3 — The attendance rule (R5, R5a, R6)

**The substance of the slice.** Prerequisites: Phases 0 and 2.

- **Files:** `src/contig/repair_stats.py`, `tests/test_repair_stats.py`.
- **Design (settled, not open):**
  - Replace `ATTENDANCE_UNKNOWN_OUTCOMES` with `GATED_OUTCOMES` — the literals producible
    **only** from the three gated call sites (`self_heal.py:1444`, `:1492`, `:1548`):
    `approved_and_retried`, `built_index_and_retried`, `index_build_failed`,
    `index_unresolvable`, `recompressed_reference_and_retried`,
    `reference_recompress_failed`, `reference_recompress_unresolvable`.
    Provable, not guessed: the safe path calls `apply_patch` directly
    (`self_heal.py:1618`) and records `patched_and_retried` (`:1643`), so it can produce
    none of these.
  - After Phase 0, `ATTENDED_OUTCOMES` is exactly the **interactive-only** set — each of
    its five literals is unreachable under `--auto-approve`. That is what makes R5a a
    one-line ordering rule rather than a special case.
  - ```python
    def classify_attendance(outcome: str, auto_approve: bool | None = None) -> str:
        if outcome not in OUTCOME_FAMILY:      return "unknown"
        if outcome in ATTENDED_OUTCOMES:       return "attended"   # R5a: literal wins
        if outcome in GATED_OUTCOMES:
            if auto_approve is None:           return "attendance_unknown"
            return "unattended" if auto_approve else "attended"
        return "unattended"
    ```
    The `ATTENDED_OUTCOMES` check **precedes** the gated check deliberately: that ordering
    *is* R5a. Comment it as such, with the asymmetry argument — relabelling a human's
    rejection as unattended inflates the gate metric in our own favour.
  - `auto_approve` **defaults** so every existing single-argument call still type-checks;
    do not make it required.
- **Steps:**
  1. RED first, all of: AC#5 (flag `True` + `approved_and_retried` → unattended, counted),
     AC#6 (flag `False` → attended, excluded from the numerator), AC#7 (flag `False` +

  3. **Preserve any-step-wins** (R8) — `tests/test_repair_stats.py:293-302` must pass

## Edge cases and error handling

| Case | Behaviour |
|---|---|
| No `launch.json` (every existing bundle) | `None` → `attendance_unknown` on gated literals; **never** `False` |
| Corrupt/unreadable `launch.json` | `None`; other runs still reported |
| Manifest predating the field | `None` (the `bool \| None` default) |
| `auto_approve: true` + an interactive-only literal | Impossible-by-construction; **literal wins**, run is attended (R5a) |
| `resume` after `run --auto-approve` | Manifest rewritten to `false`; self-consistent, pinned (AC#14) |
| Zero-event run | Unchanged: `not_analyzable`, outside both sides |
| Unmapped literal (`stopped_for_confirmation`) | Unchanged: `"unknown"` |
