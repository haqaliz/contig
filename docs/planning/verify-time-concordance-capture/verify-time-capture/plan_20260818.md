## Phase 1 — Producer `capture_metrics` out-params

**Goal:** the three evaluators surface raw pre-band `{"value", "n_shared"}` via an
additive out-param, mirroring `somatic_concordance.py:120-149`.

**Files:**
- `src/contig/verification/concordance.py` — `evaluate_concordance` +
  `concordance_results` gain `capture_metrics: dict[str, dict[str, float]] | None = None`.
- `src/contig/verification/count_concordance.py` — `evaluate_count_concordance` +
  `concordance_results` (the count core) gain the same.
- `src/contig/verification/sc_count_concordance.py` — `evaluate_sc_count_concordance`
  gains the out-param and passes it into the shared count core (one change; RNA-seq
  and sc inherit — `results_from_counts` signature is shared).
- `tests/test_verify_capture_roundtrip.py` (extend) or a new
  `tests/test_verify_capture_time.py` — RED tests first.

**Implementation steps (each RED first):**
1. RED: `test_genotype_capture_normal_and_low_shared` — build a tiny germline VCF pair
   via the `_conc_vcf`-style helpers in `test_verify_capture_roundtrip.py`; assert
   `capture["S1"] == {"value": <raw rate>, "n_shared": <float shared>}` on the normal
   path AND on the no-shared-known-GT path (value=None path must still capture
   `n_shared` — the low-n case stays self-describing, somatic precedent).
2. RED: `test_genotype_capture_absent_param_byte_identical` — with no `capture_metrics`
   arg, results equal the pre-change output (roundtrip message stability).
3. RED: `test_count_capture_normal_and_few` — count pair (via `_counts`-style helpers
   in `test_verify_capture_roundtrip.py`); `capture["S1"] == {"value": <raw rho>,
   "n_shared": <float shared>}` on normal AND too-few-shared paths (both
   `spearman_concordance` and `fraction_agreeing` UNVERIFIED paths).
4. RED: `test_sc_count_capture_uses_count_core` — sc pair (`.mtx` triplet + second
   matrix); assert the same `"S1"` shape, proving the shared core carries it.
5. GREEN: implement the out-params. For `concordance.py`: in `concordance_results`,
   when `capture_metrics is not None`, populate `capture_metrics["S1"]` from the
   `ConcordanceStats` (raw `rate` if not None else 0.0? — NO: on the `rate is None`
   path capture `{"value": None}` is NOT representable (float contract) — mirror the
   somatic precedent exactly: on the low-n path capture `{"value": <jaccard/0.0>,
   "n_shared": ...}`; here the honest choice is `{"value": 0.0, "n_shared": shared}`
   or capture the raw float rate with `n_shared=0`? **Decision: capture the raw rate
   as-is when computable; on the None path capture `{"value": 0.0, "n_shared": float(stats.shared)}`**
   — check `_concordance_status` semantics: `n_shared < min_shared (1)` → unverified,
   so `n_shared=0` yields unverified regardless of value; `n_shared >= 1` with rate
   None is impossible (rate is None exactly when no shared site has known GT → shared
   comparable is 0). Verify this reasoning against the code during implementation; the
   pin is that the stored case re-derives to the SAME status the QCResult carried.
   For `count_concordance.py`: `capture_metrics["S1"] = {"value": stats.rho if
   stats.rho is not None else 0.0, "n_shared": float(stats.shared)}` — on the
   too-few path `n_shared < 10` → unverified regardless. Document the choice in a
   comment (the `_concordance_status` floor is the honest guard, not the value).
6. REFACTOR: keep the out-param population in one helper per module; ensure absent
   param short-circuits nothing (only `if capture_metrics is not None` blocks).

**Validation:** `uv run pytest tests/test_verify_capture_roundtrip.py tests/test_verify_capture_time.py -q`
then full `uv run pytest -q` (green, 2644+ baseline).

**Commit:** `feat(verify): capture_metrics out-params on germline/RNA-seq/sc concordance evaluators`

9. REFACTOR: keep the family determination in one small pure helper (flag → family

## Testing strategy

- Unit: out-param population on normal/low-n paths (Phase 1); builder shape (Phase 2).
- Integration: CLI verify → sidecar append → promote → scorer re-derivation (Phase 3).
- Guards: four bare guard runs at the end of Phase 3.
- Command: `uv run pytest -q` after each phase.

## Environment & reproducibility

- No env vars, no network, no real tools. Autorun seams are injected and never run in
  CI (unchanged manual gate).
- Determinism: sidecar appends are the only writes; all fixtures deterministic.

## Edge cases & error handling

- Verify with no concordance flag → nothing written.
- Honest skip (`[]` from a non-matching assay or missing primary) → nothing written.
- Repeat verify → dedupe by `case_id`.
- Unreadable pending file → `append_verify_case` mkdir+append behavior (reuse as-is;
  if the file is corrupt, `load`-style skip per `verify_corpus.py:314-330` precedent —
  do not crash verify).
- Captured `rate is None` → `value: 0.0, n_shared: 0` re-derives unverified (verify
  this claim during implementation; the pin is status-consistency, not the raw value).
