# Implementation Plan: stale-rebuild (stale-index self-heal)

**Date:** 2026-08-09 · **Aspect:** `stale-index-heal/stale-rebuild` · **PRD:** `../prd.md`
**Executor:** agents team, strict TDD (RED → GREEN → REFACTOR), suite green after every phase, commit per phase on `feat/stale-index-heal/aliz`.

**Key design decisions (from PRD + user):** scratch build + atomic replace; reuse `built_index_and_retried`; scope `.fai/.bai/.tbi/.csi`; no new FailureClass, no model-on-signed-record change (no signature break); `heal_baseline.json` refreeze lands in the same commit as the scenario.

**Stale-vs-missing dispatch without a model change:** `RepairStep.diagnosis` is in the signed record, so `Diagnosis` gets NO new field. The repair distinguishes flavor by scanning the diagnosis **evidence** for the freshness phrase (`"older than"`) — pure, testable, zero signature impact. `propose_patches` is untouched (still proposes `build_index` for `missing_index`); only `_apply_patch_and_maybe_build` branches on the flavor.

**Repair mechanics (the load-bearing design):** build into run-scoped scratch `<run_dir>/healed_index/<kind>/` by **symlinking the resolved source into scratch** (same basename) and running the **unchanged** `_INDEX_BUILD` argv against the symlink — the sidecar then lands in scratch (`samtools faidx`/`index`, `tabix`, `bcftools index` all write next to their input). On a **successful** build (rc 0 AND the sidecar exists in scratch — honest empty-output check), `os.replace(scratch_sidecar, resolved_stale_sidecar)` atomically replaces the user's stale file. Failed build → user's file byte-identical. Cross-device (`os.replace` EXDEV/OSError): fallback `copy2` to a dot-temp in the target's parent + `os.replace`, dot-temp removed on failure; fallback failure → honest `index_build_failed`.

   ```python
   ]
   if stale_index_lines:
       return Diagnosis(
           failure_class="missing_index",
           root_cause="An index file is older than the data it indexes.",
           evidence=stale_index_lines,
           confidence=0.85,
       )
   ```

## Phase 2 — Repair: scratch build + atomic replace (RED first)

**Goal:** a stale-index diagnosis rebuilds the sidecar into scratch and atomically replaces the stale file, then retries — honest give-ups otherwise, user's file never half-written.

**Prerequisites:** Phase 1.

**Files:** `tests/test_stale_index.py` (new), `src/contig/self_heal.py`.

**Steps (TDD):**
1. In `src/contig/self_heal.py` add, near `_parse_missing_index`:
   ```python
   def _is_stale_evidence(diagnosis: Diagnosis) -> bool:
       """True when the diagnosis evidence names a STALE index (the freshness
       phrase), distinguishing the scratch-build+atomic-replace repair from the
       in-place missing-index repair. Pure — scans evidence lines only."""
       return any("older than" in line.lower() for line in diagnosis.evidence)
   ```
2. Add `_rebuild_stale_index(target, params, *, index_path: str, ext: str, run_dir: Path, index_builder: IndexBuilder, built_paths: set[str])` returning the same 5-tuple as `_apply_patch_and_maybe_build`. Contract:
   - Resolve the sidecar: `sidecar = Path(index_path)`; relative → `Path(run_dir)/index_path` (mirror `_resolve_dict_source`).
   - `if index_path in built_paths:` → `("index_build_failed", f"Already rebuilt {index_path}; failure persists.", False)`.
   - Derive source via `_index_build_command`'s deriver semantics: source = `sidecar-minus-ext`; if source is empty/`None` → `("index_unresolvable", ..., False)`.
   - Scratch: `scratch_dir = Path(run_dir)/"healed_index"/ext.lstrip(".")`; wipe + mkdir (STAR precedent `self_heal.py:683-687`); `src_link = scratch_dir / sidecar.name` (the SOURCE basename — NOT the sidecar name: `src_link` is the data file name, e.g. `aln.bam`).
   - `os.symlink(source_abs, src_link)` (dangling-symlink-safe; no check needed); `OSError` → `("index_build_failed", detail, False)`.
   - argv from the **unchanged** `_INDEX_BUILD` table: `_index_build_command(str(src_link), ext, run_dir)` → the sidecar lands in scratch as `src_link + ext` (same filesystem as the tool expects).
   - Add `built_paths.add(index_path)` (and the scratch dir path, STAR precedent) BEFORE invoking the builder; run `rc = index_builder(cmd, run_dir)`.
   - `rc != 0` → `("index_build_failed", f"Building the index for {index_path} failed (exit {rc}).", False)`.
   - `rc == 0` but `built_sidecar = scratch_dir / (src_link.name + ext)` does NOT exist → `("index_build_failed", "The build exited 0 but produced no index; giving up honestly.", False)` (the STAR empty-scratch precedent).
   - Stat the stale sidecar (old_mtime, if it exists); `os.replace(str(built_sidecar), str(sidecar))`; on `OSError` → fallback: `shutil.copy2(built_sidecar, dot_temp)` where `dot_temp = sidecar.parent / f".{sidecar.name}.contig-heal-{os.getpid()}"`, then `os.replace(dot_temp, sidecar)`; remove dot_temp on failure. Fallback failure → `("index_build_failed", detail, False)`.
   - Success → stat new sidecar (new_mtime) → `("built_index_and_retried", f"Rebuilt stale {index_path} (mtime {old_mtime} → {new_mtime}); argv: {' '.join(cmd)}", True)`.
3. Dispatch in `_apply_patch_and_maybe_build` (after the `kind == "star"` branch, before the existing in-place single-file path):
   ```python
   if _is_stale_evidence(diagnosis):
       return _rebuild_stale_index(
           target, params, index_path=index_path, ext=ext,
           run_dir=run_dir, index_builder=index_builder, built_paths=built_paths,
       )
   ```
   (The existing in-place path remains the missing flavor — unchanged.)
4. Write `tests/test_stale_index.py` (mirror the `_FAI_LOG`/`_fai_executor`/`_building_builder` fixture pattern at `tests/test_self_heal.py:1895-1958`). Fixtures: `_STALE_BAI_LOG` (Phase-1 log), `_stale_executor` (attempt 1 fails with the stale line, retry succeeds), `_stale_builder` (records argv, creates `argv[-1] + ".bai"` in cwd on "success"). Tests:
   - `test_self_heal_rebuilds_stale_bai_and_retries`: assert `built_index_and_retried` outcome, `patch_applied=True`, the stale sidecar under run_dir/fixtures is **replaced** (content differs, exists after), `RepairStep.detail` contains "older than" evidence + argv, the symlink was used (argv contains `healed_index`).
   - `test_stale_build_failure_leaves_user_file_byte_identical`: builder returns 1 → `index_build_failed`, sidecar bytes unchanged.
   - `test_stale_build_success_without_artifact_gives_up`: builder returns 0 creating nothing → `index_build_failed`.
   - `test_stale_rebuild_once_only`: two stale failures, same path → second is `index_build_failed` ("Already rebuilt").
   - `test_stale_unparseable_path_gives_up`: stale evidence with no index token (e.g. root_cause-only line) → `index_unresolvable`... (NOTE: `_parse_missing_index` returns None first → existing `index_unresolvable` branch handles it; pin it).

   - `test_stale_evidence_pure`: `_is_stale_evidence` true/false cases.

## Edge Cases & Error Handling

- Mixed "missing or older" wording → stale branch (ordering) → rebuild+replace fixes both.
- Build exits 0 with no artifact → honest `index_build_failed` (never a false pass).
- Cross-device replace → dot-temp copy fallback; fallback failure → `index_build_failed`, user file untouched.
- Stale sidecar missing at heal time → replace still works (rename semantics); a genuinely missing index is caught by the generic branch first when phrased with absence words.
- Build-once bounds the loop (wrong-reference masquerade cannot burn the retry budget).
- No signature break: no signed-model change; `Diagnosis` untouched; `HealScenario` additive field is fixture-only.
