   - Import `package_for_import` (from `contig.verification.import_aliases`).
   - Module constant `_MAX_INSTALLS = 2`.
   - Restructure :1217-1279 into a bounded loop:
     ```
     if exit_code != 0 and allow_install:
         seen: set[str] = set()
         installs = 0
         while exit_code != 0 and installs < _MAX_INSTALLS:
             module = detect_missing_module(run_output)
             if module is None or module in seen:
                 break
             seen.add(module)
             installs += 1
             target = package_for_import(module)
             diagnosis = Diagnosis(failure_class="missing_dependency",
                 root_cause=f"missing Python module {module!r}",
                 evidence=[run_output[:500]], confidence=0.8)
             patch = Patch(kind="env", operation={"install": target},
                 rationale=f"install {target} (import {module}) and retry",
                 risk="needs_confirmation",
                 expected_signal="run exits 0 after install")
             install_rc = installer(_pip_install_argv(target), repo_path)
             if install_rc != 0:
                 append RepairStep(attempt=installs, outcome="install_failed",
                     detail=f"pip install {target} exited {install_rc}",
                     patch_applied=False)
                 break
             exit_code, run_output = executor(shlex.split(run_command), repo_path)
             if exit_code != 0:
                 if module in seen and detect_missing_module(run_output) == module:
                     append RepairStep(attempt=installs, outcome="retry_failed",
                         detail=f"installed {target} (import {module}); retry exited {exit_code}; "
                                "same module re-detected -- not re-installing",
                         patch_applied=True)
                 else:
                     append RepairStep(attempt=installs, outcome="retry_failed",
                         detail=f"installed {target} (import {module}); retry exited {exit_code}",
                         patch_applied=True)
             else:
                 append RepairStep(attempt=installs, outcome="installed_and_retried",
                     detail=f"installed {target} (import {module}); retry exited 0",
                     patch_applied=True)
     ```

     loop iteration already handles `module in seen`; keep the loop minimal:
     record `retry_failed` with the plain detail and let the loop's
     `module in seen` guard stop it. (Simplify in REFACTOR; do not add the
     second detect.)

     module is never re-installed; the loop provably terminates".

## 6. Edge Cases & Error Handling

- Same-module re-detection → stop, never re-install (different-interpreter
  symptom; detail names it).
- No module detectable after a failed retry → break, last step `retry_failed`.
- Install rc ≠ 0 → `install_failed`, no retry (unchanged).
- Third distinct module → not chased (`_MAX_INSTALLS`).
- Unknown import → verbatim (byte-identical legacy path).
- Guard "no installer steps" → rc 1 honest fallback (unchanged).
- `RepairStep.detail` is `str | None` — never a dict; the mapping is string text.
