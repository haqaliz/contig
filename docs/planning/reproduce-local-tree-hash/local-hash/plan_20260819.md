### Phase 2 — Implement (GREEN): hash the local branch, universal exclude rule

- **Goal:** Make Phase 1 green with the minimal code change.
- **Prerequisites:** Phase 1 committed.
- **Files to create/modify:** `src/contig/bundle.py`, `src/contig/cli.py`.
- **Implementation steps:**
  1. `bundle.py` `compute_tree_sha256(root, exclude: Path | None = None)`:
     - Resolve `base = Path(root)`; keep all existing behavior byte-identical when `exclude`
       is `None` (published algorithm unchanged for the no-exclude case — R-7).
     - When `exclude` is not None, prune it like a `.git`/symlink: in the `dirnames[:]`
       comprehension, also drop any `d` where `Path(dirpath, d).resolve() ==
       exclude.resolve()` (prunes at any depth; an absolute exclude compared against the
       resolved walk path, so it works for relative and absolute roots alike).
     - All-or-`None` contract unchanged: any `OSError` → `None`, never partial (R4).
  2. `cli.py` reproduce command, at the `source_commit`/`source_tree_sha256` block
     (currently lines 1126–1139):
     - Resolve the runs dir once, pre-branch: `resolved_runs_dir = Path(runs_dir).resolve()`.
     - Remote branch: pass `exclude=resolved_runs_dir` to `compute_tree_sha256` (provable
       no-op — the runs dir is `repo_path`'s parent — pinned by the Phase-1 unit test).
     - **New local branch** (`else`): `source_tree_sha256 = compute_tree_sha256(repo_path,
       exclude=resolved_runs_dir if resolved_runs_dir.is_relative_to(repo_path.resolve())
       else None)` — placed **before** `run_started_at = time.time()` (R2) and before any
       bundle write, so the executor's own writes cannot change the recorded value.
  3. `cli.py` record population (the `if repo_argument.kind == "remote"` `model_copy`,
     currently lines 1164–1175): keep the remote block untouched (byte-identical behavior);
     add an `elif source_tree_sha256 is not None:` branch that `model_copy`s **only**
     `source_tree_sha256` onto the local record (`repo`/`source_url`/`source_commit` stay as

## 6. Edge Cases & Error Handling

- **Runs dir == repo path** (`--runs-dir .` in the repo): exclude prunes the entire tree →
  digest of the empty fold. Obscure and honest; document in the CHANGELOG entry, don't
  special-case it.
- **Unreadable file/dir during local walk** → `None` (R4), run continues, exit code unchanged.
- **Exclude path under a symlinked dir**: walk already prunes symlinked dirs before the
  exclude check would apply — order in the comprehension handles it (both filters apply).
- **Relative `--runs-dir`**: `Path(runs_dir).resolve()` against CWD (existing CLI contract).
