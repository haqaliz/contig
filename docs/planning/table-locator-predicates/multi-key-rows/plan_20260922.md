## Edge Cases & Error Handling

- Empty row object → refused at load (unchanged) and unresolved at resolve
  time (defensive `not row`).
- Non-string/empty key, non-string/bool value → refused at load; defensive
  check in `resolve_cell` returns `(None, reason)`, never raises.
- Key column absent from header → unresolved naming the column (mirror the
  single-key path at 324-331).
- Duplicate header name among key columns → unresolved (duplicate guard).
- Ragged row shorter than a key column → unresolved, no IndexError.
- Headerless table + dict row → refused at load (743-747), `(None, reason)` at
  resolve time (351-354) — unchanged.
- 0 or >1 matched rows → UNVERIFIED naming the count — never a pick, never
  DIVERGED.
- Repeated keys in the JSON object: impossible after `json.loads` (last wins);
  no handling.
- Wild inputs: every path returns `(str | None, str)`.
