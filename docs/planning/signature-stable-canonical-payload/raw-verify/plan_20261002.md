  Unreachable: reproduce.py rejects non-finite observed values (lines 987/1039/1132/1222);
  `claimed` is checked in Phase 4.

`signed_sha256` -> skip check; no cryptography -> `{"signed": True}` unchanged; BOM/CRLF in file is
irrelevant after parse.
