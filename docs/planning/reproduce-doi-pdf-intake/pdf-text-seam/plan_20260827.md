## Testing strategy

- Unit tests with `monkeypatch.setattr(paper_intake, "subprocess", fake)` —
  the module must reference `subprocess.run` through the module name so the
  patch works (do not import `run` directly at module top; use
  `import subprocess` and call `subprocess.run`).
- No real `pdftotext`, no PDFs in CI (all inputs are fake-returned strings).

## Environment & reproducibility

- Env: none. External tool: poppler `pdftotext` (user's machine only, PATH
  lookup at call time; never invoked in CI).
- Determinism: fake `subprocess.run` returns; decode with `errors="replace"`
  so arbitrary bytes cannot raise.

## Edge cases & error handling

Missing tool → `(127, …)` naming the install; non-zero exit → stderr surfaced;
stderr empty → synthesized message. No traceback on any path.
