## Phase 1: RED — classifier tests

- **Goal:** failing tests for `PaperArgument` + `classify_paper_argument`.
- **Prerequisites:** none (pure module).
- **Files:** `tests/test_paper_intake.py` (classifier section only).
- **Steps:**
  1. Test `PaperArgument` invariant: `PaperArgument(kind="doi", refusal="x")`,
     `PaperArgument(doi="10.1/x")` (no kind), `PaperArgument()` (neither) all
     raise; `PaperArgument(kind="doi", doi="10.1/x")` and
     `PaperArgument(kind="text")` construct; `PaperArgument(kind="pdf",
     doi="x")` raises.
  2. Leading-`-` tests: `"--upload-pack=x"`, `"-x"`, `"--help"` → refusal,
     message contains "command-line option"; `"-10.1234/abc"` refused (dash
     first, even DOI-shaped).
  3. DOI forms: `"doi:10.1234/abc"`, `"DOI:10.1234/abc"`, `"Doi:10.1234/abc"`,
     `"10.1234/abc"`, `"10.5555/some.suffix"` → `kind=="doi"`,
     `doi=="10.1234/abc"` (etc.); `"  doi:10.1234/abc  "` → stripped to
     `"10.1234/abc"`; `"https://doi.org/10.1038/s41586-024-00000-0"` →
     `doi=="10.1038/s41586-024-00000-0"`; `"HTTPS://DOI.ORG/10.1/x"` accepted.
  4. Refusals: `"https://doi.org/10.1/x?utm=x"` and `"10.1/x#frag"` refused
     naming `?`/`#`; `"doi:"` and `"https://doi.org/"` refused (empty
     remainder).
  5. PDF: `"paper.pdf"`, `"dir/paper.PDF"` → `kind=="pdf"`.
  6. Schemes: `"http://x/y"`, `"ftp://x"`, `"ssh://x"`, `"git://x"`,
     `"file://x"`, `"user@host:path"` → refusal mentioning supported forms
     (`doi`, `https://doi.org`, `.pdf`, `.txt`, `.md`).
  7. Text: `"paper.txt"`, `"paper.md"`, `"notes"`, `"dir/paper"` →
     `kind=="text"`, `doi is None`, `refusal is None`.
- **Validation:** `uv run pytest tests/test_paper_intake.py` — RED (module
  missing / import error counts as RED for this phase).

## Phase 2: GREEN — implementation

- **Files:** `src/contig/verification/paper_intake.py`.
- **Steps:**
  1. Module docstring: pure, stdlib-only, never touches I/O; the input-side
     classifier for `contig extract-claims` (mirrors `contig.fetch`'s
     classifier posture).
  2. `PaperArgument` frozen dataclass with `__post_init__` enforcing the
     exactly-one-of invariant.
  3. `from contig.fetch import _is_doi` (intra-package private import;
     comment why: single source of truth for DOI shape).
  4. `_DOI_URL_PREFIX = "https://doi.org/"`; `classify_paper_argument` per
     the spec decision order: leading `-` (unconditional, first); DOI forms
     (via `_is_doi` after prefix-strip, whitespace-strip, `?`/`#` refusal,
     empty-remainder refusal); `.pdf` suffix (case-insensitive); scheme
     refusal (regex `^[a-zA-Z][a-zA-Z0-9+.-]*://` not matching the doi.org
     prefix) + scp-like refusal (`^[^/]+@[^:]+:`); else `text`.
  5. Refusal messages name the reason and the supported forms; keep them
     greppable ("looks like a command-line option", "not supported", etc.).
- **Validation:** `uv run pytest tests/test_paper_intake.py` green; full
  suite `uv run pytest` green (nothing else touched).
