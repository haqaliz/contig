## Phase 1: RED — intake tests

- **Goal:** failing tests for every DOI/PDF boundary and the guard ordering.
- **Prerequisites:** all three seam commits present.
- **Files:** `tests/test_cli_extract_claims_intake.py`.
- **Steps (test list, per the spec's acceptance criteria):**
  1. Helpers: `runner = CliRunner()`; a `_scripted_fetcher(pdf_bytes)` factory
     returning a callable that writes `pdf_bytes` to `dest` and returns
     `(0, "fetched")` (records invocations); a `_scripted_extractor(text)`
     returning `(0, text)`; `_invoke(args, **kwargs)` driving
     `runner.invoke(app, args)`.
  2. Refusals and ordering:
     - DOI without `--allow-fetch` → `exit_code == 1`, `"--allow-fetch"` in
       `result.output`, `--out` not created, fetcher not invoked.
     - Leading-`-` paper arg → refusal message (classifier), nothing written.
     - `http://…` paper arg → refusal naming supported forms.
     - Existing `--out` without `--force` + DOI with flag → refuses **before**
       the fetcher runs (fetcher invocation count 0), exit 1.
     - `--out == input` still refuses for a local `.pdf` (paper not
       overwritten); a DOI paper argument does **not** trip the check (exit
       path proceeds to the `--allow-fetch` refusal instead).
  3. Success paths (scripted fetcher + scripted extractor, monkeypatched via
     `monkeypatch.setattr("contig.cli.default_paper_fetcher", f)` and
     `"contig.cli.default_pdf_text_extractor", x)`):
     - DOI + flag: draft written; `load_claims(out)` loads; sidecar exists
       with `"Source:"` line containing the DOI; fetcher received the stripped
       DOI.
     - Local `.pdf`: draft written and loads; sidecar `Source:` line has the
       PDF path.
     - Empty extraction via PDF path: `[]` draft, "no numeric claims found"
       sidecar, exit 0.
  4. Failure paths:
     - Fetcher `(1, "no citation_pdf_url found (the paper may be
       paywalled); …")` → exit 1, message in output, nothing written, no
       leftover temp (assert the temp dir is empty after the run).
     - Extractor `(127, "pdftotext executable not found …")` → exit 1,
       message echoed, nothing written.
     - Sparse-file PDF over `MAX_PDF_BYTES` (import the constant, `truncate`)
       → exit 1, size named, nothing written.
     - Scripted extractor returning text of `_MAX_MATCH_BYTES` + 1 bytes →
       exit 1, size named, nothing written.
  5. Click introspection: `--allow-fetch` and `--no-allow-fetch` in the
     `extract-claims` command's option list.
- **Validation:** `uv run pytest tests/test_cli_extract_claims_intake.py` — RED.

## Phase 2: GREEN — restructure the command

- **Files:** `src/contig/cli.py`.
- **Steps:**
  1. Imports: `classify_paper_argument`, `default_paper_fetcher`,
     `default_pdf_text_extractor`, `MAX_PDF_BYTES` from
     `contig.verification.paper_intake`; `_MAX_MATCH_BYTES` already imported.
  2. Signature: add `allow_fetch: bool = typer.Option(False,
     "--allow-fetch/--no-allow-fetch", help="Fetch a DOI's paper PDF over the
     network (a DOI is refused without it)")`; update the command docstring.
  3. Restructure the body per the spec's ordering:
     1. `paper_argument = classify_paper_argument(paper)`; refusal → echo +
        `Exit(1)`.
     2. `kind == "doi" and not allow_fetch` → echo naming the flag +
        `Exit(1)`.
     3. For `kind in ("text", "pdf")`: the existing `--out == input` block,
        unchanged.
     4. Existing `--out` without `--force` block, unchanged (all kinds).
     5. Existing `--out` directory check, unchanged.
     6. `kind == "doi"`: `tempfile.NamedTemporaryFile(delete=False,
        suffix=".pdf")` → `default_paper_fetcher(doi, tmp_path)`; non-zero →
        echo message + `Exit(1)`; then the shared PDF branch below; cleanup in
        `finally` (remove the temp file on every path).
     7. `kind == "pdf"` (and the fetched temp from `doi`): stat-before-read
        with `MAX_PDF_BYTES` (OSError / not-file / over-cap → existing refusal
        style, naming the cap); `default_pdf_text_extractor(pdf)`; non-zero →
        echo + `Exit(1)`.
     8. `kind in ("pdf", "doi")`: `len(text.encode("utf-8")) >
        _MAX_MATCH_BYTES` → refusal naming the size + `Exit(1)`.
     9. `kind == "text"`: the existing stat/read block, byte-identical.
     10. Unchanged tail: extraction, draft, round-trip, commit, sidecar,
         empty-note (pass a `source` label to the sidecar writer for
         `doi`/`pdf` kinds; `None` for `text`).
  4. Sidecar: thread a `source: str | None` parameter into the sidecar writer
     (`_review_sidecar`); when set, write a `Source: <…>` line in the header
     (DOI string for `doi`, resolved PDF path for `pdf`); when `None`, output
     byte-identical to today.

  `--allow-fetch` (the seam is the only network touch).

## Edge cases & error handling

ordering before network, over-cap PDF (sparse file), over-cap extracted text,
seam failures (fetch/extract) echoed verbatim, no leftover temp, empty
extraction exit 0, `--out == input` skipped for DOIs only.
