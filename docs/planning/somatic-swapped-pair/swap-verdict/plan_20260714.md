## Assumptions (confirmed)

- **A1** GATK Mutect2 emits `##normal_sample=<name>` in the VCF header, symmetric to
  `##tumor_sample=<name>`. The UNVERIFIED-when-absent floor (Phase 2) absorbs any deviation,
  so this is not load-bearing — a stripped/re-headed VCF simply degrades, never false-passes.
- **A2** `evaluate()` (`rule_pack.py:468-487`) **ignores** each rule's `"message"` field and
  builds its own `"{sample}: {metric}={value} ({status})"`. So S1 (naming swap/contamination)
  is done by **wrapping** the returned results' `message` via `result.model_copy(...)`, exactly
  as `strelka_vaf.py:249-252` prefixes `"Strelka2: "`. The pack `"message"` stays decorative
  (kept for parity/readability).
- **A3** Tumor and normal VAF are derived over the **same biallelic record set** and the
  **same `_vaf_from_sample` derivation**; the swap evaluator does its own streaming pass over
  the Mutect2 VCF (a second read of a small file), leaving the shipped tumor evaluator
  untouched. "Same record set", not "one shared function call" — this is the low-regression
  reading of PRD R1.

## Phase 2 — normal-column VAF reader + `evaluate_swap_plausibility`

- **Goal:** compute `normal_median_vaf` over the normal column and emit exactly one
  WARN-capped check, UNVERIFIED when uncomputable.
- **Prerequisites:** Phase 1.
- **Files:** `src/contig/verification/somatic_plausibility.py`, `rule_pack.py` (+ tests).
- **RED — write tests first** (in `test_somatic_plausibility.py`; extend `_header` to inject
  `##normal_sample=NORMAL` via the existing `extra=()` hook or a new `normal_line=True` param):
  1. **Correct pair** — normal FORMAT VAFs ~0 (e.g. `0/0:0.0:10,0:10`) → one check
     `normal_median_vaf:NORMAL`, status `pass`.
  2. **Swapped/high normal** — normal FORMAT VAFs ~0.45 → one check `normal_median_vaf:NORMAL`,
     status `warn`; message mentions swap/mislabel/contamination.
  3. **UNVERIFIED — no `##normal_sample=`** → one check, status `unverified`, `value=None`.
  4. **UNVERIFIED — normal column present but no derivable VAF** (records lack a usable normal
     FORMAT, e.g. `.` fields) → status `unverified`.
  5. **Isolation** — the returned list contains **only** the `normal_median_vaf` check; assert
     no `median_vaf`/`somatic_variant_count`/`strelka_median_vaf` check is emitted.
  6. **Gzip** — a `*.vcf.gz` input works (mirror `test_gzip_supported`, `:166-173`).
  7. **Band boundary** — normal median at 0.30 is PASS, just above 0.30 is WARN (pins the
     `warn_above` semantics against `_status_for`).
- **GREEN — implement:**
  1. Add a normal reader. Preferred: extract a private
     `_read_column_vafs(vcf_path, resolve_index)` that streams biallelic records and returns
     `(vafs, count, idx, header_lines)`, generalizing the `_read_somatic` loop (`:122-163`)
     over a `resolve_index: Callable[[list[str]], int | None]`. **Do not modify `_read_somatic`
     in GREEN** (leave the shipped tumor path byte-identical); optionally DRY it in REFACTOR.
     Acceptable simpler alternative: a `_read_normal` clone of `_read_somatic` using
     `_normal_column_index`.
  2. Add `normal_median_vaf(vcf_path) -> tuple[float | None, str | None]`: call the reader
     with `_normal_column_index`; `median = statistics.median(vafs) if vafs else None`; the
     name is `_normal_sample_name(header_lines)` when the index resolved, else `None`.
  3. Add `evaluate_swap_plausibility(vcf, sample=None) -> list[QCResult]` **structurally
     mirroring `evaluate_strelka_vaf_plausibility` (`strelka_vaf.py:208-268`)**:
     - `median, normal_name = normal_median_vaf(vcf)`; `label = sample or normal_name or "sample"`.
     - `by_metric = {"normal_median_vaf": median}`; `computable = {k: v for k, v in
       by_metric.items() if v is not None}`.
     - `results = [r.model_copy(update={"message": f"normal-sample VAF (tumor/normal swap
       check): {r.message}"}) for r in evaluate({label: computable}, SOMATIC_PLAUSIBILITY_PACK)]`
       — the wrap satisfies S1 (A2); the `by_metric` dict with only this key satisfies R5.
     - if `median is None`: append one explicit
       `QCResult(check=f"normal_median_vaf:{label}", status="unverified", value=None,
       kind="metric", message=f"{label}: normal_median_vaf could not be computed (no normal
       column found, or no derivable normal VAF)")`.
     - `return results`.
  4. Add the rule to `SOMATIC_PLAUSIBILITY_PACK` (`rule_pack.py:296-328`), after the strelka
     entry:
     ```python
     {   # normal-sample VAF: a correct tumor/normal pair has ~0 VAF in the NORMAL column
         # at somatic sites. An implausibly high normal VAF means the somatic signal is in
         # the normal -> a tumor/normal swap, a mislabel, or heavy contamination. warn_above
         # only (a low normal VAF is the healthy expected case); uncalibrated engineering
         # default, WARN-capped (no fail_*). Emitted ONLY by evaluate_swap_plausibility over a
         # by_metric dict containing just this key, so it never re-emits the rules above.
         "check": "normal_median_vaf",
         "metric": "normal_median_vaf",
         "warn_above": 0.30,
         "message": "median normal-sample variant allele fraction (high => possible tumor/normal swap or contamination)",
     },
     ```
- **Validation:** `uv run pytest tests/verification/test_somatic_plausibility.py -q`.
- **Commit:** `feat(verify): normal-sample median VAF swap smell test (WARN-capped)`

## Testing strategy

- Unit (Phases 1-2): resolver correctness + never-guess; PASS / WARN / two UNVERIFIED paths;
  isolation (only the one check); gzip; band boundary at 0.30.
- Integration (Phase 3): `run_qc` emits the check on a somatic run; exit code / verdict
  reduction unaffected (WARN-capped).
- Full suite green after every phase: `uv run pytest -q`.
- No mocks, no tool exec, no network — inline VCF strings to `tmp_path`, **no real
  nf-core/sarek or GATK run in CI**.

## Edge cases & error handling

- No `##normal_sample=` / unmatched name / multi-pair-ambiguous / tumor-only → `None` →
  UNVERIFIED (never a positional guess; PRD R2).
- Normal column resolved but zero derivable normal VAFs (empty/`.` FORMAT, tiny call set) →
  median `None` → UNVERIFIED, so a noisy 2-record VCF never WARNs (PRD R1).
- No Mutect2 VCF at all → silent skip (the shipped `if vcfs:`/mutect2-found gate owns it;
  structural QC owns a genuinely-missing output).
- WARN-only always: `warn_above` with no `fail_*`, so the check can never change the exit code
  or the verdict reduction beyond WARN.
